
# Sorting Algorithm Visualizer

## Project Overview
An interactive Python application that visualizes sorting algorithms using graphical representations.

## Features
- Visualizes Bubble Sort and Insertion Sort.
- Supports ascending and descending order.
- Generates random lists of numbers.
- Provides real-time sorting visualization.
- Allows users to select algorithms using keyboard controls.

## Technologies
- Python
- Pygame
- Random and Math libraries
